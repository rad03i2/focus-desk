# Contributing

Thanks for improving Focus Desk. Keep changes focused, local-first, and dependency-light.

1. Fork and create a descriptive branch.
2. Run `npm test` before submitting changes.
3. Keep domain logic in `src/core.js` so it remains testable without a browser.
4. Do not introduce analytics, remote storage, trackers, or secrets without an explicit design discussion.
5. Update both English and Arabic README sections when user-facing behavior changes.

Use clear commits and describe behavior, tests, accessibility impact, and privacy impact in pull requests.

## المساهمة

نرحب بالمساهمات. شغّل `npm test` قبل إرسال التغييرات، وحافظ على مبدأ التشغيل المحلي والخصوصية، وحدّث القسمين الإنجليزي والعربي عند تغيير سلوك المستخدم.
